# Roadmap and current status

**v0.1 — working educational prototype**
- Pure-Python DCF and valuation by market multiples.
- Financial ratios with explicit validation.
- Basic macroeconomic time-series growth and rebasing.
- Simple moving averages and Wilder RSI.
- Weighted financial scoring and deterministic ranking.
- Plain-text financial metric extraction.
- Synthetic demo and automated tests.

**Ideas, not implemented**
- Configurable financial-statements schema and robust cross-format ingestion.
- Auditable data source connectors using openly licensed public feeds.
- Backtesting with survivorship-bias controls.
- DCF sensitivities, scenarios, unit and currency handling.
- Charting interface and optional web dashboard.
- LLM-assisted parsing with evidence, traceability, evaluation and explicit user review.
- Data provenance logs, CI, packaging, security auditing.

## Guiding principles

1. No proprietary work products or licensed datasets.
2. Never confuse fabricated demonstrations with actual issuer results.
3. Always name assumptions and denominator definitions.
4. Prefer reproducibility and transparency to unsupported claims of AI autonomy.
5. Audit source data and code before deploying or using for investment decisions.
