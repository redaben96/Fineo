# Contributing

Thank you for your interest.

- Contributions must be original or appropriately licensed.
- Never submit confidential files, private research, personal data, access tokens, client names or proprietary employer code.
- Use synthetic data for tests and examples.
- Run `python -m unittest discover -s tests -v` before proposing changes.
- Describe assumptions and accounting definitions in financial calculations.
- Changes that could affect financial outputs should include tests and clear limitations.
